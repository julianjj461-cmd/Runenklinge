# Runenklinge

Ein Fantasy-Clicker fürs Handy: Tippe, um Monster zu besiegen, rüste Mara aus, lerne Talente, sammle Relikte und Artefakte.

**Spielen:** https://julianjj461-cmd.github.io/runenklinge/

Das ganze Spiel steckt in einer einzigen Datei (`index.html`). Der Spielstand wird im Browser gespeichert.
